# AGIRE — نسخة العميل لويندوز

هذه الحزمة مستقلة: لا تحتاج إلى تثبيت .NET أو SQL Server أو أدوات برمجية أخرى.

## التشغيل لأول مرة

1. استخرج ملف ZIP بالكامل إلى مجلد ثابت على جهاز يعمل بنظام Windows 64 بت.
2. شغّل `AGIRE-Setup.exe`.
3. أدخل بريد مدير المنصة وكلمة مرور من 8 أحرف على الأقل.
4. يبدأ الخادم محلياً وتُفتح صفحة تسجيل الدخول في المتصفح الافتراضي. بعد الإعداد، استخدم اختصار AGIRE على سطح المكتب.

احتفظ بمجلد الحزمة في مكانه؛ ملفات التشغيل والبيانات موجودة بداخله. لا تشغّل البرنامج من داخل ZIP ولا تنقل ملف EXE وحده.

## ملفات الحزمة

- `AGIRE-Setup.exe`: تشغيل المنصة والإعداد الأولي.
- `REST.exe`: إعادة الإعداد الأولي بعد التحقق من بيانات المدير. العملية تعيد قاعدة البيانات إلى إعداد جديد؛ تنشئ نسخة احتياطية قبل ذلك.
- `payload`: ملفات التطبيق وقاعدة البيانات المحلية.

## بيانات المنصة

تُحفظ قاعدة البيانات ومفاتيح الجلسات والسجلات داخل `payload/data`. انسخ هذا المجلد إلى وسيط آمن لإجراء نسخة احتياطية. لا تحذف قاعدة البيانات إذا كنت تريد الاحتفاظ ببيانات العملاء والفواتير.

تعمل هذه النسخة على الجهاز الذي شُغّلت عليه، وتفتح عبر `http://localhost:5182`. لا تفتح المنفذ على الإنترنت.

## عند تعذر التشغيل

تأكد من استخراج جميع الملفات، ومن استخدام Windows 64 بت. سجلات التشغيل موجودة في `payload/data`. إذا منع Windows تشغيل الملف، راجع رسالة الحماية الظاهرة قبل المتابعة.
