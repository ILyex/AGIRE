# النموذج المرئي السابق — AGIRE

نموذج محلي مرئي سابق لإدارة زبائن الوكالة الوطنية للتسيير المدمج للموارد المائية (AGIRE)، والفواتير والدفعات والديون وقراءات استهلاك المياه. المنصة الرئيسية الحالية موجودة في `src/web/Hawdh.Portal`.

## التشغيل

افتح `index.html` في Microsoft Edge أو Chrome، أو شغّل `تشغيل_المنصة.bat` على Windows. لا يحتاج التطبيق إلى تثبيت أو اتصال بالإنترنت. الخطوط الثلاثة (Plus Jakarta Sans وIBM Plex Sans Arabic وJetBrains Mono) محفوظة محلياً داخل مجلد fonts.

## المزايا

- لوحة متابعة تعرض عدد الزبائن، المبالغ المستحقة والمحصلة، استهلاك الشهر، مخطط التحصيل وحالة الفواتير.
- إدارة بيانات الزبائن والبحث والتصفية وتعطيل الزبون مع الاحتفاظ بسجلاته.
- إصدار فواتير بأرقام تلقائية، تسجيل دفعات كاملة أو جزئية، وتتبع تاريخ الاستحقاق.
- تسجيل قراءات الاستهلاك وحساب الفرق وقيمة الاستهلاك، مع إنشاء فاتورة تلقائية عند تحديد سعر الوحدة.
- تنزيل تقرير Excel متوافق مع Microsoft Excel وLibreOffice، ويتضمن أوراق الملخص والزبائن والفواتير والدفعات والاستهلاك.
- تنزيل نسخة احتياطية JSON واستعادة البيانات منها.

## التخزين والخصوصية

تُحفظ البيانات في التخزين المحلي للمتصفح على الجهاز الحالي. احفظ نسخة احتياطية دورية من صفحة «التقارير والتصدير». حذف بيانات المتصفح أو استخدام متصفح/جهاز آخر لا ينقل البيانات تلقائياً.

## ملاحظات الإصدار الأول

هذه نسخة أولية تعمل دون خادم، ومناسبة للاستخدام على جهاز واحد. لم تُضف بعد إدارة المستخدمين والصلاحيات، المزامنة بين الأجهزة، الطباعة الرسمية، أو تكامل المحاسبة. لا تتضمن بيانات تجريبية؛ ابدأ بإضافة الزبائن الحقيقيين.

صيغة التصدير هي Excel XML بامتداد `.xls` لضمان إنشاء تقرير متعدد الأوراق دون اعتماد على مكتبات خارجية؛ يفتحه Excel وLibreOffice مباشرة.
